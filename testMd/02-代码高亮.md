## SQL

```sql
SELECT
    r.review_id,
    r.rating,
    t.topic_name
FROM platinum_bi.mv_voc AS r
LEFT JOIN platinum_foundation.fact_voc_topic AS t
    ON r.review_id = t.review_id
WHERE r.moderation_status = 'approved'
ORDER BY r.rating DESC
LIMIT 100;
```
