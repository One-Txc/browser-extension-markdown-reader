## English Heading

这是一个英文标题，它的 id 应该是 `english-heading`（小写、空格转连字符）。

## 中文锚点标题

中文标题的 id **应当保留中文字符本身**，而不是被编码成 `%E4%B8%AD%E6%96%87...`。

这是为了让你在 Markdown 里手写 `[跳转](#中文锚点标题)` 时能真正跳过来。

如果你点击上面的「跳到『中文锚点标题』」能滚动到这里，说明锚点生成正确。

## 带标点的标题：测试！

标点（中文冒号、感叹号）应当被从 id 中移除，空格转连字符。

预期 id 为 `带标点的标题测试`。
