Just Markdown —— 在浏览器里，所见即所得地阅读 Markdown
一款轻量高效的浏览器扩展，让你在浏览网页或本地文件时，直接以渲染后的排版阅读 Markdown 文档，无需下载、无需切换工具。
核心能力
✔ 多协议支持：兼容 file://、http://、https://，可预览 .md、.markdown、.txt 等文档。
✔ 丰富语法：支持表情、上下标、任务复选框、数学公式、流程图、甘特图、自动目录、脚注、提醒标记等扩展语法。
✔ 文档大纲：内置侧边栏目录，支持原始内容一键切换预览。
✔ 图片体验：支持图片点击放大、多图切换。
✔ 主题美观：提供高质量多套主题与代码高亮。
❗️❗️在浏览【本地文件】前，请手动开启 Chrome 扩展程序的【允许访问文件网址】权限❗️❗️：
在 Chrome 扩展管理中，进入 Just Markdown 的详细信息页，启用 "允许访问文件 URL " 选项即可。


Just Markdown —— What You See Is What You Get Markdown Reading in Your Browser
A lightweight and efficient browser extension that lets you read Markdown documents with rendered formatting directly while browsing the web or viewing local files—no downloads or switching tools required.
Core Features
✔ Multi-protocol Support: Compatible with file://, http://, and https:// protocols. Supports previewing .md, .markdown, .txt, and other document formats.
✔ Rich Syntax: Supports extended syntax including emojis, superscripts/subscripts, task checkboxes, math formulas, flowcharts, Gantt charts, auto-generated tables of contents, footnotes, and alert markers.
✔ Document Outline: Built-in sidebar navigation with a one-click toggle to switch between rendered preview and raw content.
✔ Enhanced Image Experience: Supports click-to-zoom for images and easy switching between multiple images.
✔ Beautiful Themes: Comes with high-quality themes and code highlighting.
❗️❗️ Important: Before browsing [Local Files], please manually enable the "Allow access to file URLs" permission for the Chrome extension ❗️❗️:
Go to the Chrome Extensions management page, open the details page for Markdown Read, and toggle on the "Allow access to file URLs" option.
