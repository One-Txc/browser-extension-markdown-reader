## 详细描述

### 简体中文

```
Markdown Read 让浏览器直接读懂 Markdown —— 打开 .md 文件或访问返回 Markdown 的网址，看到的是排版好的文档，而不是一屏带 # 和 * 的纯文本。

全部在浏览器内完成，不需要装任何本地服务或命令行工具。

■ 阅读体验
· 完整的 Markdown 渲染：标题、列表、表格、引用、任务列表、脚注
· 代码块语法高亮，鼠标移上去可一键复制
· 数学公式（KaTeX）：$行内$ 与 $$块级$$
· Mermaid 图表：流程图、时序图、类图、甘特图、饼图等
· 点击图片全屏放大，支持滚轮缩放、拖动平移
· 一键切换到原始 Markdown 源码视图
· 9 套代码配色 + 5 套护眼配色，深浅色可跟随系统

■ 导航
· 左侧大纲：按标题层级生成目录树，滚动时自动高亮当前章节
· 目录树可逐级折叠，也有「全部 / 第一层 / 前两层 / 前三层」的批量按钮
· 左侧文件夹：列出当前文档所在目录，点一下就切换文档，不用回文件管理器

■ 更多
· 界面支持简体中文 / English / 日本語 / 한국어，可手动切换
· 所有设置改完立即生效，不需要刷新页面
· 渲染后页面地址不变，相对路径图片、文档互链、Ctrl+F 查找、打印都正常可用

■ 关于权限
扩展需要「允许访问文件网址」才能读取你打开的本地 .md 文件。这是 Chrome 的安全要求，无法绕过。
扩展不收集任何数据，不联网上传任何内容，详见隐私政策。
```

## Chrome 权限说明

Chrome Web Store 要求逐项解释权限用途。后台里有对应的填写项：

| 权限 | 填写内容 |
|---|---|
| `storage` | 保存用户的偏好设置（配色、字号、界面语言等）。 |
| `scripting` | 在页面中注入图表渲染脚本。仅当文档确实包含 Mermaid 图表时才触发。 |
| **主机权限**<br>`file:///*` | 读取用户打开的本地 Markdown 文件，以及列出该文件所在目录（用于侧边栏的文件夹面板）。 |
| **主机权限**<br>`http://*/*`、`https://*/*` | 识别用户访问的在线 Markdown 文档并渲染。扩展只读取当前页面的内容，不会访问其他网页。 |

**关于「读取您在所有网站上的数据」这条提示的说明**（可放在审核备注里）：

> 扩展需要注入到 http(s) 页面，是因为无法在清单里预先限定「只匹配 Markdown」——
> 服务器返回的 Content-Type 不一定正确，网址也未必以 .md 结尾。
> 实际筛选在运行时进行：先看 `document.contentType`，若是 `text/plain` 再检查路径后缀，
> 不匹配时立即返回，不对页面做任何改动。

## 截图

商店要求至少 1 张，建议 3–5 张。Chrome 的推荐尺寸是 **1280×800**。

建议按这个顺序截，能体现完整价值：

| # | 场景 | 要点 |
|---|---|---|
| 1 | 一个内容丰富的文档 | 侧栏大纲展开（体现层级与高亮）、代码块、表格同框 |
| 2 | 文件夹面板 | 展开状态、排序设置面板可见、某一行处于选中态 |
| 3 | 数学公式与 Mermaid 图表 | 用 `testMd/` 里的对应文档 |
| 4 | 护眼配色 | 切到豆沙绿或羊皮纸，与浅色形成对比 |
| 5 | 设置面板 | 展示分组与多语言 |

> 截图里不要出现真实的私人路径或文件名（`C:\Users\你的名字\...`），
> 建议用 `D:\docs\` 这类中性路径。
