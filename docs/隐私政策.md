# 隐私政策

**MD Reader 不收集、不上传、不共享任何用户数据。**

最后更新：2026-10-10

---

## 一句话说明

本扩展是一个纯本地的 Markdown 阅读器。它读取你指定的文件或网页内容，在浏览器里渲染成排版好的文档，
**整个过程不产生任何网络请求，也不保存任何阅读记录**。

## 具体说明

### 我们不收集什么

- ❌ 不收集个人信息（姓名、邮箱、账号等）
- ❌ 不收集浏览记录、阅读过的文档列表
- ❌ 不收集文档内容
- ❌ 不使用任何统计、分析或埋点工具
- ❌ 不投放广告
- ❌ 不向任何第三方传输数据

### 数据存在哪里

扩展只有一项需要保存的东西：**你的偏好设置**（配色、字号、界面语言、侧边栏宽度等）。

这些设置通过浏览器提供的 `chrome.storage.sync` 接口保存。它的行为是：

- **保存在你的浏览器里**
- 如果你登录了浏览器账号并开启了同步，它会**在你自己的设备之间同步**（由浏览器厂商处理，不经过我们）
- 卸载扩展时，这些设置会被删除

除偏好设置外，扩展不保存任何其他信息。

### 网络访问

扩展申请了 `http://*/*` 与 `https://*/*` 的访问权限，用途是**识别并渲染在线 Markdown 文档**：

- 当你访问一个返回 Markdown 内容的网址时，扩展读取**当前这个页面**的内容并渲染它
- 这个读取是浏览器加载页面本身的行为，扩展**不会额外发起任何请求**
- 扩展不会访问、读取或上传你访问的其他网页

### 本地文件的访问

扩展申请 `file:///*` 权限，用于读取你打开的本地 `.md` 文件，以及列出该文件所在目录的内容
（用于侧边栏的「文件夹」面板）。

这些文件只在你的浏览器中读取和显示，**不会被上传到任何地方**。

> Chrome 要求扩展显式获得用户授权才能访问本地文件。你可以在 `chrome://extensions` 里随时关闭这项权限。

## 权限用途一览

| 权限 | 用途 |
|---|---|
| `storage` | 保存你的偏好设置 |
| `scripting` | 在页面里注入生成图表所需的脚本（Mermaid），仅在文档包含图表时触发 |
| `file:///*` | 读取你打开的本地 Markdown 文件与所在目录 |
| `http://*/*`、`https://*/*` | 识别并渲染在线 Markdown 文档 |

## 第三方组件

扩展打包了若干开源库（Markdown 解析、代码高亮、数学公式、图表渲染等）。
它们全部**在本地运行**，不会发起网络请求，也不会收集数据。

## 儿童隐私

本扩展不面向儿童，也不收集任何年龄相关信息（因为它不收集任何信息）。

## 政策变更

若本政策有实质性变更，会在扩展更新说明与本文件中注明。
